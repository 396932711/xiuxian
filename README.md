# 《宗门》— 国风亲子共玩 · 休闲放置养成游戏

> 孩子化身"掌门"亲自下场，和父母一起从零建立修仙宗门。**零依赖、零构建**，双击或起个本地 HTTP 服务器就能玩；**所有数值 / 名字库 / 主题 / 建筑元数据都外置 JSON**，家长孩子记事本就能调整体验，不用改代码。

## ✨ 特色亮点

- 👨‍👩‍👧 **亲子共玩设计**：孩子代入"掌门"角色，有专属头像（可上传自己 Q 版图片）、可打工、可升级、可带全员士气加成
- 🌱 **放置休闲**：10 秒一 tick，自动生产 + 2 小时离线收益，孩子不操作也能成长
- 🎨 **国风 Q 版美术**：青绿 + 原木 + 暖金主色，飞檐翘角简化建筑，圆润字体
- ⚙️ **全参数可配置化（v1.3）**：6 份 JSON 覆盖产出、升级、招募、名字库、主题色、资源元数据；改 JSON → 刷新 → 立即生效
- 🛡️ **健壮容错**：即使本地双击 `file://` 打开、或 JSON 字段缺失/类型错，也能自动回退到内嵌默认值，孩子视角**永远不会黑屏报错**
- 📦 **存档导入/导出/重置（v1.3.1 新增）**：底部导航「设置」一键导出 `.json` 备份 / 从备份文件导入跨机器接着玩 / 带「输入确认词」二次保护的重开新档
- 🧱 **模块化迭代**：每阶段一个可玩闭环（阶段1 已交付），后续叠加药田·丹房·筑基、战斗·秘境·金丹、宗门高阶玩法

## 🎮 快速开始（2 种方式，任选其一）

### 方式 A：HTTP 服务器（**推荐**，会实时读取 6 份 JSON 配置）

```bash
cd /workspace
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

### 方式 B：双击 `index.html` 本地直接玩

> 孩子自己电脑玩、不想搭服务器的场景。由于浏览器 CORS 限制，本地 fetch JSON 会失败，程序会**自动回退**到 `assets/config.js` 里内嵌的 `DEFAULTS` 镜像。玩法、数值完全一致，只是改 `assets/config/*.json` 不会实时生效（想调参请用方式 A）。

## 🧭 玩法一分钟速览

```
建立宗门（默认掌门"小掌门"，可改名+上传Q版头像）
    │
    ├─ 掌门亲自分配至「灵矿场」→ 产出灵石（掌门加成×1.5，且全员士气+10% ✅）
    │
    ├─ 前往「招募堂」花 50 灵石 → 招入国风名字新弟子（名字库随机，可改名）
    │
    ├─ 弟子也分配至矿场 → 灵石产出变快
    │
    ├─ 攒够 100 灵石 → 升级「宗门大殿」/「灵矿场」→ 弟子上限 / 工位上限 / 产出提升
    │
    ├─ 每 10 秒 tick，掌门和弟子自动获得经验 → 练气 Lv.1 → Lv.10
    │
    └─ 关掉页面 2 小时内再回来 → 离线收益弹窗："离线期间收获灵石 ×N"
```

## 🛠️ 如何不碰代码调游戏（亲子调参指南）

所有可调项目都在 `assets/config/` 下的 6 份 JSON。详细字段字典见 **[《配置文件总览.md》](./docs/配置文件总览.md)**。

| 想做的事 | 改哪份 JSON | 改什么字段 |
|---|---|---|
| 让孩子**玩得更爽**（产出变高、升级变快） | `values.json` | `produce.basePer10s` ↑ / `exp.growthMul` ↓ |
| 招募**更便宜更频繁** | `values.json` | `recruit.cost` ↓ / `recruit.cdBaseSeconds` ↓ |
| 离线**能攒 4 小时**（当前 2 小时） | `values.json` | `offlineCapSeconds = 14400` |
| 把爸爸/妈妈的姓加进新弟子名字 | `name_library.json` | `surnames` 数组追加 `"爸爸姓"` |
| 把宗门主色从青绿 → **紫霞主题** | `ui.json` | `themeColors.qing = "#8C5EFF"` |
| 把"弟子"按钮改叫 **"同门"** | `ui.json` | `uiText.bottomNav[0] = "同门"` |
| 开局就送 500 灵石 | `resources.json` | `lingshi.initialValue = 500` |
| 新增阶段 2 建筑"药田"（代码补逻辑前先挂元数据） | `buildings.json` | `order` 加 `"yaotian"` + `buildingMeta.yaotian` 条目 |
| 降低练气→筑基突破难度 | `realms.json` | `realms.lianqi.breakthrough.baseSuccessRate = 0.95` |
| 想把孩子的进度**备份到爸爸电脑**继续玩 | 不碰配置 | 游戏内 底部「设置」→ 📦 导出 → 拷文件 → 爸爸电脑「设置」→ 📥 导入 |
| 担心孩子误清空进度 | 不碰配置 或 `values.json` | 重置前会强制输入「重置」二字；想更严格改 `saveFile.confirmResetWord = "和爸爸一起重建宗门"` |

**操作步骤**：用记事本/VSC 打开对应 JSON → 保存 → 刷新浏览器页面 → 立刻看到效果 ✨

## 🧪 开发 / 调试小贴士

- **冒烟 6 场景**（v1.3 验收已通过）：HTTP 模式 / file:// 双击 / 改数值实时生效 / 删字段静默回退 / 换主题 CSS 变量 / 增姓氏随机出现
- **存档文件迁移**（v1.3.1）：
  - 底部导航「设置」→ 📦 **导出存档**自动下载 `宗门-存档-{宗门名}-{掌门名}-{年月日时分}.json`
  - 底部导航「设置」→ 📥 **导入存档**选择刚才导出的 JSON（兼容 F12 `getItem` 直接存的 raw JSON，和包壳的 JSON 两种格式）
  - 「🔄 重置存档」带二次输入验证：默认要输入「重置」二字，确认词可在 `values.saveFile.confirmResetWord` 改成更严的长句
- **临时改数值调试**：F12 控制台直接 `GameConfig.values.produce.basePer10s = 10`，下一 tick 生效；但刷新就失效，正式改动必须写回 JSON
- **调试存档隔离**：临时把 `values.storageKey` 改成 `"zongmen_save_debug"`，与孩子的正式进度互不干扰
- **扩展新功能的顺序**（铁律）：**① 决定放哪份 JSON 加字段 → ② 同步 `assets/config.js` 的 `DEFAULTS` → ③ 写代码读 `GameConfig.xxx.yyy` 或 `H.*` → ④ 配置文件总览补说明 → ⑤ 设计文档第六章标注配置来源**。禁止先写代码再抽配置。

## 💾 用户数据存放位置说明

《宗门》是**零后端单机页游**，游玩产生的数据**不会写入磁盘文件**，全部保存在**浏览器 localStorage**（按域名独立，约 5MB 容量）：

- **默认存档 Key**：`values.storageKey = "zongmen_save_v1"`
- **备份 / 迁移 / 恢复方式**：用游戏内「设置 → 📦 导出 / 📥 导入」按钮直接下载/上传 JSON 文件（最推荐，孩子也能操作）
- **查看 / 备份 / 清档（开发者方式）**：F12 → Application → Local Storage，或在控制台执行：
  ```js
  // 查看完整存档
  JSON.parse(localStorage.getItem('zongmen_save_v1'))
  // 手动备份字符串（可粘贴到记事本保存为 .json，再回游戏导入即可）
  localStorage.getItem('zongmen_save_v1')
  // 重置存档（不如用游戏内设置的「🔄 重置」更安全）
  localStorage.removeItem('zongmen_save_v1'); location.reload()
  ```
- **掌门自定义头像**：以 DataURL 形式存在 `state.leader.avatarDataUrl` 字段中（默认压缩 ≤256KB，防止 localStorage 爆）。
