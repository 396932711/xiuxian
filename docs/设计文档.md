# 《宗门》休闲养成游戏设计说明

> **版本**：v1.1
> **修订记录**：
>
> * v1.1：基于循环与资源链评审，修正突破石阶段冲突、数值曲线、补全离线收益/状态机/招募堂阶段/战斗兜底等定义。
>
> * v1.0：初版设计。

## 一、游戏核心定位

* **游戏名称**：宗门

* **游戏类型**：国风修仙题材 · 休闲放置养成游戏

* **目标用户**：亲子共玩（偏向儿童易懂的轻量化玩法，无复杂操作）

* **核心体验**：从一名修仙者从零建立宗门，通过招募弟子、分配生产、升级建筑与境界，逐步壮大宗门规模，主打"看得见的成长"和低门槛的放置收益，适合和孩子分步开发、逐步解锁功能。

* **开发原则**：模块化迭代，每阶段完成一个可玩闭环，让孩子全程参与设计与验证，逐步叠加新系统。

## 二、核心玩法循环

**基础闭环**：招募弟子 → 分配至不同建筑岗位 → 自动产出资源 → 消耗资源升级建筑/提升弟子境界 → 解锁更多建筑与玩法 → 扩大宗门规模

**成长主线**：宗门大殿等级提升 → 解锁新建筑/新岗位上限 → 弟子境界突破 → 产出效率提升 → 挑战更高阶内容

## 三、分阶段开发路线（亲子渐进式）

### 阶段1：最小可玩原型（基础宗门）

**目标**：做出最核心的"建宗门+收灵石"循环，孩子能直观看到成果

* 开放**1种基础资源**：灵石

* 开放**2个核心建筑**：宗门大殿、灵矿场

* 开放**招募堂**（功能建筑，阶段1即开放，供招募弟子）

* 开放**弟子基础功能**：招募、分配至灵矿场采集、自动产出灵石

* 开放**基础升级**：升级宗门大殿提升弟子数量上限；升级灵矿场提升产出效率

* 开放**练气境界**（1-10级），弟子可通过修炼升级提升采集效率

### 阶段2：生产体系拓展（药田+炼丹）

**目标**：增加资源链，让孩子参与设计"资源转化"逻辑

* 新增**灵药资源**，开放**药田建筑**，弟子可种植灵药

* 新增**丹药资源**，开放**丹房建筑**，消耗灵药炼制丹药

* 新增境界：**筑基境**（1-10级），弟子练气满级后可突破至筑基

* 新增**藏经阁**：提供修炼速度加成

* 新增日常任务：引导孩子完成资源收集、建筑升级目标

### 阶段3：弟子成长与战斗体系

**目标**：加入战斗与探索，丰富玩法维度

* 新增境界：**金丹境**（1-10级），后续预留元婴、化神等扩展位

* 开放**演武场/秘境**：派遣弟子出战，击败妖兽获得稀有资源与突破材料

* 新增弟子天赋：根骨（修炼速度）、悟性（炼丹/战斗加成），招募时随机生成

* 新增装备雏形：简单的法器，提升弟子属性

### 阶段4：宗门高阶玩法

**目标**：深化策略性，由孩子自由设计高阶内容

* 新增建筑：阵法阁、灵兽园、任务大厅等

* 新增宗门科技：消耗资源激活全局加成

* 新增弟子师徒系统：高阶弟子带低阶弟子加速修炼

* 新增宗门声望：吸引更优质的弟子前来投奔

## 四、核心系统详细设计

### 1. 资源系统

| 资源类型 | 产出途径              | 主要用途                          |
| :--- | :---------------- | :---------------------------- |
| 灵石   | 灵矿场弟子采集、任务奖励、战斗掉落 | 建筑升级、弟子招募、修炼消耗、基础兑换           |
| 灵药   | 药田弟子种植            | 炼制丹药、境界突破辅助材料                 |
| 丹药   | 丹房弟子炼制（消耗灵药）      | 弟子修炼加速、战斗回血、突破成功率提升           |
| 突破石  | 秘境战斗掉落、高阶任务       | **金丹境及以上**大境界突破必备材料（筑基突破仅需丹药） |
| 宗门贡献 | 弟子完成任务产出          | 兑换稀有图纸、提升弟子待遇                 |

> **突破石阶段说明（v1.1 修订）**：原设计中突破石仅在阶段3秘境产出，但筑基突破（阶段2）即需要，存在阶段冲突。修订为：**筑基突破只需消耗丹药，无需突破石；突破石自金丹境起为必备材料**。这样阶段2的生产链（药田→丹房→丹药）可自闭环，孩子能独立完成筑基突破，不会卡在缺材料上。

### 2. 建筑系统

所有建筑均有等级，升级消耗灵石+对应材料，等级越高产出/加成越高，部分建筑需宗门大殿达到指定等级解锁。

* **宗门大殿（核心）**

  * 功能：决定宗门整体等级，限制其他建筑最高等级、弟子总数量上限

  * 升级效果：提升弟子上限、解锁新建筑类型、解锁新境界上限

* **灵矿场（生产）**

  * 功能：分配弟子自动采集灵石

  * 升级效果：单名弟子产出效率提升、可分配弟子工位增加

* **药田（生产）**

  * 功能：分配弟子种植灵药，有成熟周期

  * 升级效果：成熟速度加快、产量提升、工位增加

* **丹房（生产）**

  * 功能：分配弟子炼丹，消耗灵药产出丹药

  * 升级效果：炼丹速度加快、高阶丹药解锁、工位增加

* **招募堂（功能）**

  * 阶段：**阶段1即开放**（v1.1 明确）

  * 功能：消耗灵石招募随机弟子，等级越高刷出高品质弟子概率越大

  * 升级效果：刷新CD缩短、高品质弟子概率提升

* **演武场（功能，阶段3）**

  * 功能：派遣弟子修炼加速，或组队挑战秘境

  * 升级效果：修炼加成提升、可挑战秘境层数增加

### 3. 弟子系统

#### （1）境界与等级

* 每个大境界分为10个小等级，当前境界10级满后，消耗突破材料可突破至下一大境界

* 境界顺序：练气 → 筑基 → 金丹 → 元婴 → 化神（后续可扩展）

* 境界越高，基础属性越强，生产/战斗效率越高，可担任的岗位越高级

* **突破材料规则（v1.1 修订）**：

  * 练气 → 筑基：仅消耗丹药（基础成功率80%，丹药可提升至100%）

  * 筑基 → 金丹 及以上：需消耗突破石 + 丹药

#### （2）弟子属性

* 姓名：随机生成国风名字，支持孩子自定义改名

* 境界/等级：决定基础能力

* 天赋：根骨（修炼速度）、悟性（生产/战斗加成），分为凡、良、优、绝四个品级

* 状态：空闲、采集中、种植中、炼丹中、修炼中、战斗中

#### （3）状态机（v1.1 新增）

弟子在以下状态间转换，规则如下：

```
空闲 ──分配岗位──> 采集中 / 种植中 / 炼丹中
采集中 / 种植中 / 炼丹中 ──召回──> 空闲
空闲 ──派遣修炼──> 修炼中（演武场或闲置自动修炼）
修炼中 ──召回──> 空闲
空闲 ──组队──> 战斗中（阶段3秘境）
战斗中 ──战斗结束──> 空闲
```

* **切换规则**：除战斗中外，任意生产/修炼状态可随时召回至空闲，**召回时当前批次进度保留**（已采集/已炼制的部分产出，未完成的不损失），避免孩子误操作挫败。

* 战斗中的弟子不可中途召回，需战斗结束。

#### （4）操作

* 招募：在招募堂消耗灵石招募

* 分配：点击建筑后将空闲弟子分配至对应岗位

* 修炼：派遣至演武场或闲置时自动缓慢获得经验

* 突破：满等级后手动点击突破，消耗对应材料

### 4. 任务引导系统

* **主线任务**：跟随宗门升级节奏，引导解锁新建筑、新功能，奖励大量资源

* **日常任务**：每日刷新，如"采集100灵石""招募1名弟子"，奖励丹药与贡献

* 任务设计偏向简单明确，适合孩子理解和完成目标

### 5. 战斗系统（阶段3开放）

* 模式：自动回合制战斗，无需复杂操作

* 场景：秘境副本，分多层，每层有妖兽守卫

* 规则：派遣1-3名弟子组队挑战，胜利后掉落资源与突破材料

* 特点：数值碾压为主，搭配简单的境界克制，低龄孩子也能看懂

* **撤退兜底（v1.1 新增）**：战斗中可主动撤退，**撤退无损**（弟子不受伤、不消耗已派遣资源），仅本次挑战不计入掉落。让孩子"打不过就跑"，避免挫败感。

## 五、美术风格与UI设计规范（供AI生成）

### 1. 整体美术风格

* **风格定位**：Q版卡通国风 · 清新明亮仙侠风

* **画面质感**：扁平化+柔和光影，线条圆润，无尖锐棱角，适合儿童审美

* **主色调**：以青绿色、原木色、暖金色为主，搭配浅白云雾背景，整体色调柔和不刺眼

* **人物设计**：Q版二头身，弟子服饰为简约古风道袍，不同境界用服饰颜色区分（练气灰、筑基青、金丹金）

* **建筑设计**：Q版古风仙侠建筑，飞檐翘角简化处理，每个建筑有明显功能特征（灵矿场带矿石、药田带植物、丹房带丹炉）

### 2. 核心界面布局与元素说明

#### （1）宗门主界面（核心场景）

* **顶部栏**：从左到右依次显示 宗门等级、灵石数量、灵药数量、丹药数量，图标+数字形式

* **中间主区域**：俯瞰视角的宗门场景，建筑错落分布，点击对应建筑弹出升级/管理面板

* **底部导航栏**：4个功能按钮，从左到右：弟子、建筑、背包、任务

* 背景：远山+云雾+仙气粒子效果，整体氛围宁静清新

#### （2）弟子界面

* 左侧：弟子列表，显示头像、名字、境界、状态

* 右侧：选中弟子详情，包含属性面板、修炼按钮、突破按钮、分配岗位按钮

* 风格：卡片式布局，圆角边框，不同境界卡片底色不同

#### （3）建筑升级弹窗

* 顶部：建筑名称+当前等级

* 中间：升级效果说明、升级消耗资源

* 底部：升级按钮（资源足够高亮，不足灰色）

* 风格：半透明国风面板，带简单云纹装饰

#### （4）招募界面

* 中央：招募卷轴/招募牌视觉

* 下方：招募按钮、招募消耗、刷新倒计时

* 招募结果：弹出弟子卡片，有简单的光效反馈

### 3. 图标与控件规范

* 按钮：大圆角矩形，有明显的按下/悬浮反馈，主按钮用金色，次要按钮用木色

* 图标：线性+填充结合，国风简约风格，识别度高

* 文字：清晰易读的圆润字体，标题字号大，正文字号适中，避免生僻字

* 弹窗：统一带半透明遮罩，面板从底部弹出或居中弹出，关闭按钮明显

## 六、基础数值框架（雏形）

> **v1.1 数值修订**：原升级递增 +50%、经验递增 +30% 叠加后曲线偏陡，儿童在第3级左右易卡顿。阶段1升级递增下调至 +30%，弟子基础产出系数上调，目标让孩子3分钟内看到首次升级。

1. **弟子产出**：练气1级弟子基础产出 **1.5灵石/10秒**（v1.1 由1上调），每级提升10%，大境界突破后基础翻倍
2. **建筑升级**：1级升2级消耗100灵石，**每级消耗递增30%**（v1.1 由50%下调）
3. **经验与等级**：练气1升2需100经验，每级需求递增30%；演武场修炼速度为5经验/10秒
4. **突破概率**：练气升筑基基础成功率80%，可用丹药提升至100%；金丹及以上需突破石+丹药

## 七、离线收益规则（v1.1 新增）

放置游戏必须定义离线累计上限，平衡资源产出与防溢出：

* **离线累计上限**：**2小时**（120分钟）。超过2小时的离线时间不再累计产出。

* **离线产出计算**：按弟子当前岗位的产出效率 × 离线时长（封顶2小时）计算，回到游戏时一次性结算。

* **离线提示**：回游戏后弹窗显示"离线期间收获：灵石 ×N"，让孩子直观看到放置收益。

* **离线范围**：仅生产类岗位（采集/种植/炼丹）累计；修炼、战斗不累计。

* **上限可扩展**：后续可通过宗门科技/建筑升级提升离线上限（如升至4小时），作为长线成长点。

## 八、亲子参与设计建议

1. 阶段1：让孩子绘制宗门场景草图、给第一个弟子起名字，代入感更强
2. 阶段2：和孩子一起设计丹药名称、药效，讨论"灵药怎么变成丹药"的逻辑
3. 阶段3：让孩子设计妖兽形象和秘境名字，发挥想象力
4. 每个功能上线后先让孩子试玩，根据反馈调整数值和操作，培养产品思维

### v1.0 · 阶段1最小可玩原型（已确认范围，待开发）

**目标**：做出最核心的"建宗门+收灵石"循环，孩子能直观看到成果。

**实现功能**：

1. **资源系统**
   - 仅灵石 1 种资源

2. **建筑系统（3 个）**
   - 宗门大殿（核心）：升级 → 提升弟子数量上限、解锁其他建筑等级上限
   - 灵矿场（生产）：分配弟子采集灵石；升级 → 单弟子产出效率提升 + 工位增加
   - 招募堂（功能）：消耗灵石招募弟子；升级 → 缩短刷新CD + 提升高品质弟子概率

3. **弟子系统**
   - 招募（招募堂消耗灵石，随机生成国风名字）
   - 分配至灵矿场采集
   - 练气境界 1-10 级（仅本境，**不含突破至筑基**）
   - 修炼升级提升采集效率
   - 状态：空闲 / 采集中（召回无损，保留当前批次进度）

4. **自动产出与离线收益**
   - 灵矿场弟子自动产出灵石
   - 离线收益 2 小时上限，回游戏一次性结算弹窗

5. **基础数值**
   - 练气1级弟子：1.5 灵石/10秒，每级 +10%
   - 建筑升级：1→2 级 100 灵石，每级 +30%
   - 经验：练气1→2 需 100 经验，每级 +30%

6. **UI 界面**
   - 宗门主界面（顶部资源栏 + 建筑场景 + 底部导航）
   - 建筑升级弹窗、招募界面、弟子界面

7. **数据持久化**
   - localStorage 本地存档

**明确不含**（留待后续版本）：筑基突破、药田/丹房/藏经阁、日常任务、弟子天赋、战斗/秘境、装备。

**验收标准**：孩子能在 3 分钟内完成"招募1名弟子 → 分配至灵矿场 → 看到灵石增长 → 升级一次矿场/大殿"的完整闭环，并能离线后回来看见收益。
